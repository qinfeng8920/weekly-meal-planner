# 七天食谱算法

1. 读取当前档案和最新体重。筛查异常和医学风险，然后计算目标。
2. 对每道菜检查过敏、忌口、屏蔽、设备、时间、厨艺、乳品/果品及冷冻限制。开启预算时，过滤所有缺少净料单价的配方。对未知外食的安全或营养无法校验，会提示自带便当或更改用餐设置。
3. 使用确定性随机数挑选一组主食、主菜、蔬菜和相应餐次，偏好可提高权重。固定早餐、锁定菜、指定菜先占用位置。一周禁重复设置适用于早餐菜、主菜与蔬菜，主食、加餐与整果按份量可复用。减少浪费时降低对重复使用的惩罚。
4. 在允许范围内优化各道菜的份量，调整当天果量，然后校验。按优先启动耗时菜、依次备料和分配不同加热厨具估算每餐时间。单日搜索上限 2200 次，禁重复时 3000 次。最多保留 12 个合格备选并按目标偏差、重复和偏好评分。
5. 周计划检查果蔬多样性、成本和全周菜类重复。每次换菜、换餐、换日和调整克数都会重新检查整周。无法通过时保留已有方案并提示原因。
6. 按保存时的档案、人数和厨具同步计算购物与备餐。采购、备餐、烹饪步骤、营养、随机种子和版本均随历史方案独立保存。

同一档案、限制、库存价格、锁定信息、配方和算法版本，以及同一随机种子，可复现每道菜和份量。日期、方案 ID 与创建时间包含环境因素。有限搜索出现无解提示时，有可能仍存在没有采样到的组合。
