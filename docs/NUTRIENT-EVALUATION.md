# V3.2.2 营养评价与配餐

## 参考值和状态

适用参考来自《中国居民膳食营养素参考摄入量（2023 版）》成人表 9–14、20–23。按档案公式使用的性别、年龄及健康适用条件选择。50～64 岁女性的铁参考有两种口径，页面同时列出有月经和无月经的数值。肾脏疾病、特殊医嘱及其他需评估的档案沿用应用的适用检查，仅显示成分用量。 [18～49 岁参考表](https://www.cnsoc.org/drpostand/) · [50 岁及以上参考表](https://www.cnsoc.org/drpostand/page2.html)

| 参考值 | 用途 |
| --- | --- |
| EAR 平均需要量 | 完整的计划用量低于该值时标记摄入不足，供调整计划参考 |
| RNI 推荐摄入量 | 标记未达、达到或高于推荐摄入量 |
| AI 适宜摄入量 | 标记是否达到适宜量，低于 AI 时无法单据此判定不足 |
| PI-NCD 慢病预防建议摄入量 | 按表核对最低建议量或最高建议量 |
| UL 可耐受最高摄入量 | 仅用于有明确上限且口径匹配的成分，达到上限的 85% 触发应用预警 |

例如 18～64 岁成人的钠同时列出 1500 毫克 AI 与至多 2000 毫克 PI-NCD。钾列出 2000 毫克 AI 与至少 3600 毫克 PI-NCD。当前成人表未列钠、钾、镁的通用膳食 UL。叶酸用 DFE 核对 EAR 与 RNI，合成叶酸的 UL 只用于强化食品或补充剂中的合成形式。总维生素 A 使用 RAE，UL 只用于预成型视黄醇。界面标明其他口径差异，例如烟酸与烟酸当量、总糖与添加糖。补充剂和计划以外摄入未纳入计算。

日视图逐项列出已知小计、用料重量覆盖率、缺值及状态。周视图另外按日期列出低于 EAR、接近或超过 UL、超过 PI-NCD 最高建议量或膳食比例建议的情况。数据缺失时不从部分用量推断摄入不足，已知量足以触发的提醒仍会显示。计划数据用于比较估算摄入。

## 数据及烹调口径

- 配餐和详情读取同一套按可食部称量状态索引的成分。每份菜由基准值乘实际原料克重；每餐的每个用料只累计一次。已保存的营养和执行快照沿用原记录。
- 采用 USDA 第 6 版中已核对的保留率行 `3005`、`3455`、`3775`、`3464`、`3784`、`0381`、`0432`。仅在原料状态与烹调方法匹配时换算，例如焯煮沥水的生菠菜。已有熟食成分直接使用；汤汁被食用、方法未匹配或未确认损失时沿用对应原料值。原料出成率用于采购和分装，保留率用于营养估算。 [USDA 第 6 版烹调营养保留率](https://www.ars.usda.gov/ARSUserFiles/80400525/Data/retn/retn06.pdf)
- 低钠盐单独保存配方 ID `lowsalt75`。按质量比 75% 氯化钠、25% 氯化钾，分别用钠和钾的原子量占对应盐分子量的比例计算。每 1 克约含钠 295.05 毫克、钾 131.12 毫克。普通食盐、低钠盐与酱油各按使用克重累计。酱油等成品沿用成分库对应参考产品，实际品牌配方以标签为准。 [低钠盐试验配方](https://pubmed.ncbi.nlm.nih.gov/34459569/) · [标准原子量](https://www.ciaaw.org/abridged-atomic-weights.htm)
- 低钠盐需要成人在档案主动选择。限制钾摄入或存在钾排泄风险时，按健康筛查和页面适用条件处理。当前选项只对应标注为 75∶25 的配方。 [WHO 低钠盐替代品指南](https://www.ncbi.nlm.nih.gov/sites/books/NBK612035/)

## 生成与替换

候选同时比较单日和滚动日均的营养缺口。达到对应 RNI 或 AI 后，继续增加该项摄入不再提高得分。钾的合理摄入评分使用食物中的钾；调味料中的钾也计入报告。钠按档案年龄执行保守采购配餐限值，仍显示为 PI-NCD。真正的 UL 参与风险排序和单日校验。营养不足参考用于优化顺序，保留原有能量、过敏、厨具、食材池和执行状态约束。

当前 225 条成分记录、38 项成分。新增视黄醇和合成叶酸两列由已核对来源导入；低钠盐增加公式可追溯的成分记录。未知、微量及来源报告零在数据层保持区分。 [全库审计](NUTRIENT-AUDIT.md) · [逐食材缺值报告](NUTRIENT-GAPS.csv)
