# V3.2 多档案存储

IndexedDB 仍使用原站点与 app object store。首次打开时在同一事务中读取旧 data、校验完整资料、写入 profiles-v2 并移除旧键。校验或写入失败会回滚。空的旧个人档案只要有旧记录，仍随旧对象一起迁移。导入支持旧版单档案 JSON。

新结构包含公共主题、最近选择的档案编号，以及独立 UUID 和修订号的档案。每个档案保存旧结构的完整数据。更新时校验编号及修订，整个事务保留其他档案。已打开的标签页可继续使用它选中的档案，新标签页和刷新采用最近选择。删除后旧写入会失败。切换会取消运行中的生成，清除打开的页面、搜索和弹层状态。

单档案恢复默认创建独立副本，用户可明确选择覆盖特定档案。全量合并跳过已存在的来源编号，替换全部时分配新本地编号，以隔离旧页面中的未完成写入。两个导入操作都在完整解析后原子提交。公共主题可由全量替换恢复。备份在本机处理，文件含健康信息。

需求和隐私边界见 [V3.2 最终指令](PRD-V3.2.md)。
