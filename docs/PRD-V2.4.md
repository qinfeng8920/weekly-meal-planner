# 天天减 V2.4 · 全品类食材库、食谱大全与智能替换

V2.3.2 为升级基线。延续四项主导航、长期库存、价格、采购去重和分批备餐，不恢复制作时间上限。食材库增量可独立浏览，每周仍优先集中采购。

1. 用核心食材判断换食材。仅改变制作方法单列为换做法。允许指定菜谱、整餐、随机更换，候选不足时保留原食谱。
2. 使用完整候选搜索和分页，显示库存、本周已用、预计补购与受限原因。严格食材池外的候选须明确确认。过敏、忌口、厨具、已执行状态始终由引擎复核。
3. 长期目标为 500 种以上原料与 1,000 道以上基础菜谱。优先核对华南常见食品，分别统计独立食材、原料商品、基础菜谱和审核变体。
4. 食材记录注明状态、标准 ID、别名、分类、成分原始来源、价格和采购商品。未知值保留为空，已有的经验证生熟换算与即食商品互相独立。
5. 食谱大全提供分类、全文搜索、餐次、方式、厨具、营养、收藏与库存筛选。详情显示可执行步骤、相关菜谱、变体与成本。可设必选菜或选一个待执行餐位进行校验替换。
6. 原材料大全为独立页面。提供一级、二级分类，按名称、别名、拼音检索，显示对应称量状态、营养、来源、价格、库存与可选操作。
7. 默认复用库存、优先食材和核心食材。水果支持固定、少量轮换、丰富多样，以及只修改某天或整周待执行的水果。
8. 改动后更新营养、采购净重、包装、库存抵扣、预算、批次及分装。保持实际付款、已购、取用、锁定和历史快照。
9. 分页渲染，支持离线、Web Worker、数据库审计与可重复导入。用至少 100 个种子、不同预算库存、360／390／430 像素视图和真实旧版 PWA 核对。

未达到数据建设目标时，记录实测数字、营养缺失、暂缺可执行菜谱和数据授权。上线由 GitHub Pages 自动化验证。
