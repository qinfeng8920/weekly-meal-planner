# V2.0 审计与实施顺序

附件原文见 PRD-V2.md。基线为 V1.3.0，仓库 main 头为 9373d47，生产功能代码为 963df14。

| 区域 | 基线可复用 | V2 缺口 |
| --- | --- | --- |
| 菜谱与配餐 | 标准食材 ID、餐次/同类去重、179 道菜、健康与营养校验、烹饪模式 | 候选来自全库，周内种类只受评分影响。没有提前选定的周食材池或换菜新增食材确认 |
| 采购与价格 | 128 条已区分来源的价格、收据、包装、可食率、独立采购/备餐周期、历史报价 | 只有计划用量和已购，缺可靠的分装/制作/实际领用进度及批次账本视图 |
| 备餐 | 逐菜食用和制备日期、安全冷链、每份重量 | 批次工时仍串行相加，缺标签与默认展开当前批 |
| 网站 | 五个入口、浅深色、IndexedDB、离线缓存、Pages 流程 | 首页大图占屏，常用流程分散，生成主线程运行 |

执行顺序：先确认基线与布局，随后完善食材池及兼容结构，接入生成和换菜，再接执行账本及批次视图，最后统一页面、转移生成到 Worker、回归、部署。

## 手机低保真布局

- 首页：紧凑页头 → 今天三餐 → 主操作（生成或继续备餐）→ 下一批与采购费用 → 折叠体重趋势。
- 独立生成页：采购集中度与选择方式 → 已选食材和锁定 → 烹饪、采购、备餐和预算 → 高级设置 → 生成。
- 食谱：本周食材概览 → 七天日条 → 宏量摘要 → 按餐紧凑菜行 → 展开营养、做法和更换。
- 采购：费用和进度 → 汇总 / 分批 / 备餐 / 库存 / 价格 → 分类与行内价格。
- 备餐：周期时间轴 → 当前批库存取用、补购 → 标签与勾选 → 操作顺序与复热。
- 菜谱：搜索和标签 → 可选厨具与复杂度过滤 → 菜名与用时。
- 我的：当前档案摘要 → 分组设置 → 历史与备份。

保留固定底栏。界面重构在业务派生数据和兼容策略稳定之后进行。
