# 界面规范

移动优先，底部导航为首页、食谱、采购、菜谱库和我的。主题提供系统、浅色、深色三档。主色为森林绿，背景为暖白，正文和操作优先使用本地系统中文字体。首页先展示今日食谱与采购备餐，保留体重趋势和营养目标。

卡片、标签、按钮、表单均有文字标签，触控交互一般至少 44 像素高。键盘可访问主要控件，表单和生成错误通过文本及对应的警报角色呈现。底栏兼容系统安全区域。采购数量、时间和营养标注单位。

V2 的生成页集中展示食材池、采购与备餐设置。食谱通过每天的日条切换，微量营养和菜谱操作按需展开。采购页按周汇总、分批采购、分批备餐、食材价格、家中库存切换。备餐默认展开当前或下一批，保留冷藏条件、生熟分开和熟饭安全提示。
