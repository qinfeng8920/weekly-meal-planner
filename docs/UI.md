# 界面规范

V3.0 设计令牌、页面结构和复现方法见 [V3.0 界面设计系统](UI-V3.md)。
移动优先，底部导航为首页、食谱、采购和我的。菜谱库与收藏在「我的」。主题提供系统、浅色、深色三档。主色为森林绿，背景为暖白，正文和操作优先使用本地系统中文字体。首页先展示今日食谱与采购备餐，保留体重趋势和营养目标。

卡片、标签、按钮、表单均有文字标签，触控交互一般至少 44 像素高。键盘可访问主要控件，表单和生成错误通过文本及对应的警报角色呈现。底栏兼容系统安全区域。采购数量、时间和营养标注单位。

V2 的生成页集中展示食材池、采购与备餐设置。食谱通过每天的日条切换，微量营养和菜谱操作按需展开。V2.1 采购页保留采购清单和备餐清单。周汇总折叠在采购内，价格和家中库存移入「我的」。备餐默认展开当前或下一批，保留冷藏条件、生熟分开和熟饭安全提示。

V2.2 用批次、分组、普通行三套样式区分层级。批次标题保留日期和重点操作，分组用浅色底及固定方向箭头，普通行左对齐名称并右对齐重量和金额。详细步骤、逐份重量和流水都按需展开。库存默认显示实际剩余量大于零的食材，展开后可查看流水或修改。适配系统字体放大及浅色、深色主题。

备餐每批分为食材取用与分装、调味料用量、制作步骤、储存与复热。当前批次优先展开，本批集中制作和以后各日的现做、复热时间分别显示。

V2.3 采购勾选后就地确认数量、单位和付款，净重与日期折叠。部分补买从同一行登记新凭证。已执行餐提示锁定，查看菜谱仍可使用；纠正实际取用由备餐或库存流水操作。
