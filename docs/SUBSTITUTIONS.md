# V2.3.1 食材替换覆盖

逐项审核 129 个营养食材 ID（含生熟别名和独立即食选项）。启用 3 条 A 级方向规则、1 条有独立工序的 B 级规则，生成 86 个受限配方变体。14 个 B 级用途组只允许换经过验证的完整菜谱。生熟映射仍沿用原五条出成率规则。

直接变体按原位置核对调味用途和工序。菜籽油与橄榄油只用于适合的蒸、煮、凉拌工序。番茄牛肉糙米碗有单独的水煮加油做法，保留牛肉中心温度和熟饭复热要求。苹果醋可在相容即食配方内换无调味米醋，按原调味重量起调并试味。禁止在腌制保存或关键酸度工序用该规则。 [无调味米醋用途及酸度](https://kikkomanusa.com/products/rice-vinegar/) · [米醋营养原始记录](https://fooddb.mext.go.jp/details/details.pl?ITEM_NO=17_17016_7)

不同奶与豆浆、全蛋与蛋清、鱼与虾或豆腐、坚果与油、生抽与醋须重新选择合格餐次。缺少审定规则的商品保留同一 SKU，只按用量和库存优化。没有可靠密度的油、醋仍按克计价，已填写规格时可换算。
