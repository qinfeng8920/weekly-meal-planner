# 变更记录

## 2.0.0

- 在选食谱前建立周食材池。支持采购集中度、手动严格限定、库存优先、锁定、排除、替换、轮换和收藏模板。
- 保留既有餐次模板、语义去重、厨具及每日能量和营养校验。增加四种快手一锅餐，换菜涉及新采购食材时先确认。
- 增加分装标签、完成与取用记录、实际库存核验、可撤销扣减、安全跨周结转。批次提供并行工时、复热和费用。
- 压缩首页，独立生成设置，采购行内改价，菜谱增加厨具和复杂度过滤。生成移至可取消的 Web Worker。升级继续使用原 IndexedDB。
- 验收情况见 [测试记录](TESTING.md)。

## 1.3.0

- 引入 128 种原料的广东人民币参考价，区分监测、类别参考、估算与用户价格。
- 按食谱拆分独立采购和备餐批次，配置采购方式、备餐周期和自定义日期。
- 分开核算净料消耗、整包参考采购与实际支付，区分实际确认与预计包装结余。
- 支持单项与批次复制、价格库备份恢复、历史价格快照和主动重估。沿用已有个人档案与 IndexedDB。

## 1.2.0

- 增加食材语义和搭配互斥，同餐识别酸奶、鸡蛋、核心肉类和重复主食。
- 增加极简、简单、家常、精致、混合五种模式，支持分日、分餐和本次生成覆盖。
- 新增 19 道快捷、炖煮、备餐及精致菜谱。展示主动、等待、提前制作与复热时间，并可按快捷操作调整。
- 旧版 IndexedDB、档案、历史和体重继续读取，烹饪字段按需新增。

## 1.1.0

- 160 道菜采用独立餐次标签，新增 43 套早餐搭配，早餐默认最多 10 分钟。
- 新增三餐各自偏好、固定与重复策略、按槽换菜和分餐能量目标。合格搭配再按偏好、钙和其他营养指标、用时和多样性排序。
- 日和周营养视图显示钙、钾、维生素 C、膳食纤维和钠的参考差距与数据缺失。
- 保留旧 IndexedDB、历史和备份结构。PWA 回到联网前台后检查新缓存。
