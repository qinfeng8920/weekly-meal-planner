# 变更记录

## 2.4.0

- 替换按核心食材去重。换做法单独浏览，指定与随机候选支持搜索、分页、库存排序和明确的补购确认。
- 「我的」增加食谱大全和原材料大全。分类、拼音、相关菜谱、库存、价格和偏好入口使用同一套食材资料。
- 增加固定水果与按日例外。批量换水果只应用于待执行、未锁定的水果菜品，重新验证营养和采购。
- 扩充 95 条可追溯食材记录，保留具体营养缺失。两套大全按需加载，PWA 预缓存全部离线资源。

## 2.3.2

- 采购行的食材、已购状态、采购量与详情各自留有空间。包装规格另行显示，长规格在手机放大字号时正常换行。

## 2.3.1

- 采购在真实商品和库存口径上比较整周候选。三个模式同步优化，优先比较需买商品数、需求费用和库存抵扣。
- 新增受限油醋配方、米醋营养条目和各品类用途审查。已有生成设置增加折叠的常用商品偏好，菜谱详情可选择适合的替代做法。
- 库存支持单项、全部清空与撤销。实际购买、付款及历史数据由原账本保留。

## 2.3.0

- 已执行菜品锁定，重生成保留已执行餐次。新方案使用独立任务范围，冻结旧实际取用。
- 按支付日期合并计划内外费用，实付、参考估值、待购和消耗价值分别显示。
- 少量种类增加蛋奶豆和坚果复用。配餐先取实际可称重的份量再验证营养。
- 一致的同日工序集中煮熟或称量，独立储存要求分别处理。
- 采购勾选先确认实购，同商品可以补买和更正。检测到其他操作先写入时，读取最新资料并保留原账本。

## 2.2.1

- 采购批次、分类和全周汇总折叠时仍显示已购项数。已购与部分购买在食材行单独标记。

## 2.2.0

- 食材与调味料采用独立的长期库存账本。实际购买入库，实际取用扣减，来源可核对和撤销。跨周跨月结转，取消库存有效期及自动失效。
- 采购区分主要食材、新鲜调味食材和常备调味料。按库存抵扣补购，继续使用原来的购物次数和备餐批次。调味料按批汇总并保留菜谱用量。
- 手机端统一标题、分组、列表行和展开箭头。备餐划成四组，集中备餐与后续制作时间分别列出。
- 升级自动迁移已确认购买、手工余额和有效取用凭证，保留旧资料及备份。同一来源可能重叠的库存可在家中库存核对。

## 2.1.0

- 用采购商品 ID 汇总生熟用量。自制熟食按出成率折算为生料或干料，用户可修改出成率或明确选购即食商品。
- 采购次数按独立购物日计算，支持 1、2、3 次及自定义。备餐保留合法七天拆分，可以同时设每周采购 2 次、按 2＋2＋3 备餐。
- 生成不按烹饪分钟数筛选、评分或校验。烹饪偏好为简单、家常、不限制。按本轮补充要求，储存条件用于安全提示与备餐操作。
- 新食谱可从今天、明天或下周一开始，默认明天。四项导航，采购只保留两个主栏目，首页和食谱共用生成设置。
- 原始营养、生熟库存状态、旧价格、实际付款、执行记录和历史快照继续保留，PWA 使用新版缓存。

## 2.0.0

- 在选食谱前建立周食材池。支持采购集中度、手动严格限定、库存优先、锁定、排除、替换、轮换和收藏模板。
- 保留既有餐次模板、语义去重、厨具及每日能量和营养校验。增加四种快手一锅餐，换菜涉及新采购食材时先确认。
- 增加分装标签、完成与取用记录、实际库存核验、可撤销扣减、安全跨周结转。批次提供并行工时、复热和费用。
- 压缩首页，独立生成设置，采购行内改价，菜谱增加厨具和复杂度过滤。生成移至可取消的 Web Worker。升级继续使用原 IndexedDB。
- 验收情况见 [测试记录](TESTING.md)。

## 1.3.0

- 引入 128 种原料的广东人民币参考价，区分监测、类别参考、估算与用户价格。
- 按食谱拆分独立采购和备餐批次，配置采购方式、备餐周期和自定义日期。
- 分开核算净料消耗、整包参考采购与实际支付，区分实际确认与预计包装结余。
- 支持单项与批次复制、价格库备份恢复、历史价格快照和主动重估。沿用已有个人档案与 IndexedDB。

## 1.2.0

- 增加食材语义和搭配互斥，同餐识别酸奶、鸡蛋、核心肉类和重复主食。
- 增加极简、简单、家常、精致、混合五种模式，支持分日、分餐和本次生成覆盖。
- 新增 19 道快捷、炖煮、备餐及精致菜谱。展示主动、等待、提前制作与复热时间，并可按快捷操作调整。
- 旧版 IndexedDB、档案、历史和体重继续读取，烹饪字段按需新增。

## 1.1.0

- 160 道菜采用独立餐次标签，新增 43 套早餐搭配，早餐默认最多 10 分钟。
- 新增三餐各自偏好、固定与重复策略、按槽换菜和分餐能量目标。合格搭配再按偏好、钙和其他营养指标、用时和多样性排序。
- 日和周营养视图显示钙、钾、维生素 C、膳食纤维和钠的参考差距与数据缺失。
- 保留旧 IndexedDB、历史和备份结构。PWA 回到联网前台后检查新缓存。
