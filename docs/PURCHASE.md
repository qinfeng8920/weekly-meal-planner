# 采购、备餐与广东价格

## V2.1 的采购口径

用量保留两种口径。营养继续读取菜谱原生食材和生熟状态。采购以单独的实际商品 ID 汇总。熟鸡胸、熟糙米、清煮红薯、熟玉米和煮鸡蛋默认折算到相应的生料或干粮。鸡蛋清、鸡腿、不同酸奶、加工豆腐、鲜鱼和无盐罐头各自计量。菜谱中开罐即用的无盐熟鹰嘴豆保留独立商品。明确选择购买某种无盐即食熟料时，该品单独计价。

出成率为熟重除以生料或干料的可食净重。熟鸡胸水煮或蒸初始 75%，煮糙米初始 280%，清煮红薯 90%，水煮玉米粒 95%，带壳水煮蛋 98%。程序记录方法、参考来源和版本，以上是可编辑估算。切法、去皮、加水量和烹饪方法都会影响结果，建议用同一批食材实测调整。先把熟料除以出成率得到原料可食净重，仅对待购部分按可食率折成毛重，再按包装规格向上取整。未知出成率标记待补充。 [USDA 肉禽烹调出成率](https://www.ars.usda.gov/ARSUserFiles/80400525/Data/retn/USDA_CookingYields_MeatPoultry.pdf) · [USDA 食品采购指南](https://foodbuyingguide.fns.usda.gov/)

排定购物日后，按最接近且不晚于需求的购物日汇总缺口。预定日期与备餐区间分别生成。旧设置「一次采购」优先保持一次，「随备餐采购」兼容为两次，其他旧模式沿用档案的采购次数。新版保存后只读独立采购设置，额外已发生的购买登记另列。库存按实际商品和生熟口径分配。熟料仅用于相应熟料需求。

## 保留的批次、费用和库存能力

- 备餐周期支持每天、每 2 天、每 2～3 天、每 3～4 天、每周及自定义。合法拆分完整覆盖七天。
- 消耗费用按实际食谱用量折算，计划采购费用按整包和购买事件计算。未知价格标记待补充，实际支付与参考估价分别展示。
- 当前份量、人数、价格与库存联动。历史方案冻结原始商品、数量、报价及凭证快照。主动重估只更新预览。
- 备餐分装同时展示菜谱原始净重和采购净料折算。可登记完成与取用，重复勾选保持幂等，撤销按原来源归还。预计库存不会代替实际库存。

## V2.2 的分类和长期库存

- 主要食材、新鲜调味食材和常备调味料分别汇总。普通葱姜蒜和油盐只汇总批次用量，各道菜仍显示具体用量，所有用量继续纳入营养及过敏校验。
- 确认购买在同一份 IndexedDB 资料内记录实际数量、单位、净重、支付金额和来源，并更新账本。份量改动按差额修正。缺少包装或密度时，填写实测净重或补充规格。采购确认、手动补充、取用、手动扣除、报损和撤销均可查询。若部分货物已扣用，撤销购买前须核对用量。
- 当前真实余额由流水重建。购买日期只用于查询和费用归属。跨周库存按食谱需求分配，同一份可用量只分配一次。预计采购和包装结余属于预算。生成、换菜、保存及删除历史均保留真实账本。
- 实际取用可从备餐批次、分装项或食谱餐次登记。确认前可改实际重量，库存不足会整笔拦截。制作和食用沿用已记录的同一份取用；撤销时按原来源归还。
- 升级按确定性 ID 导入确认购买、手工库存及已取用凭证。旧手工余额可能包含同项购买时，重叠部分保留为待核对。原始凭证、旧价格及历史快照随完整备份保留。
- 食材是否仍适合食用由用户核对。库存保存在此浏览器。更换手机、清除站点数据前请先导出完整备份。

## 查看采购进度

批次、分类和全周汇总的折叠标题会显示已购项数。全周按批次累计，同一种食材若需要在两个批次分别购买，分别计入进度。已登记部分实购量的行显示「已买部分」，补足后计入已购。库存已覆盖、不需要购买的行不计入待购项数。

## 食品安全

没有冰箱时，易腐品宜在食用当天取得并制作。选定购物日保持固定，保存条件不足的食材在清单单独提示。只有冷藏时，普通熟食的计划提前量最多一天，熟米饭优先现做。叶菜及生鲜水产优先食用当天处理，带冷冻室才建议提前冻结鱼虾生料；另有当日购买现做选项。避免对已经熟制并需要复热的米饭再次安排提前烹熟。分装冷却、解冻及复热要求以以下资料为依据。 [FoodSafety.gov 冷藏时间](https://www.foodsafety.gov/food-safety-charts/cold-food-storage-charts) · [FoodSafety.gov 安全处理](https://www.foodsafety.gov/keep-food-safe/4-steps-to-food-safety) · [英国食品标准局米饭指引](https://www.food.gov.uk/print/pdf/node/4286) · [USDA 安全温度](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures)

## V2.3 实购与费用

勾选后先确认实购数量、单位和实付，净重与日期设置按需展开。修正已有凭证和再次购买使用不同入口。再次购买产生独立流水，同一天同一商品可登记多次。

七天费用按真实购买日期归属。计划外购买同样计入该日期范围。已登记实付、已买未填金额的参考估值及待购估计分开展示，三者组成预计总支出。食材消耗价值使用实际上已取用及未执行部分的预计用量，按可得价格估算。类别、批次和周汇总都包含本周相应费用。缺少单价保留待补充。

备餐按食材取用、调味、集中制作、分装与储存排列。只在做法、制备日期与保存方式一致时集中煮熟，糙米的预计出成率使用已有参考。生鸡胸可按同一时段统一称量后分别调味。集中步骤勾选记录进度，实际扣减仍通过原任务的取用入口，重复提交不会重复扣减。实领已包含同款熟食时，集中制作只安排仍需加工的原料。

## V2.3.1 库存清空

单项在库存食材详情操作，批量在「库存管理」操作。清空前确认范围，随后核算采购量、预计金额与备餐来源。流水按原库存批次追加扣减，实付、购买凭证、历史快照、实际取用和锁定任务保持原记录。撤销会按原批次把当时清掉的数量加回，因此后来新买或调整的库存也会保留。最近一次可直接撤销，早期清空可在对应流水查看并撤销。

采购页顶部区分使用种类和待买种类。已有库存覆盖的食材归入独立折叠区。液体按有据可查的克重换算显示毫升或升；未配置可靠密度时显示克重。瓶、盒、袋等使用实际计价规格，未标明包装类型时显示规格克重。
